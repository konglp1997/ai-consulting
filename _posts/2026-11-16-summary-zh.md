## [OpenAI 与 GPT-6 Astra 推进标准模型的格点定义](https://openai.com/index/step-toward-defining-the-standard-model) ⭐️ 8.0/10

OpenAI 宣布了一个标准模型的候选非微扰格点定义，该工作在其 GPT-6 Astra 模型的协助下完成，Astra 帮助将该想法转化为详细的证明。 这项工作可能为超越微扰论研究标准模型提供严格基础，影响理论物理学，并展示了 AI 在高级数学和科学研究中日益增长的作用。 该公告是一篇简短的博客文章而非完整论文，证明的细节和验证状态尚未完全公开；GPT-6 Astra 此前曾解决数学问题，其证明由 Lean 4 证明助手验证。

## [Meta FAIR 与 NYU：视觉编码器预训练可选，视觉专用参数不可或缺](https://www.reddit.com/r/MachineLearning/comments/1xx1k2o/meta_fair_nyu_unbundling_multimodal_vision/) ⭐️ 8.0/10

Meta FAIR 与 NYU 在匹配的计算预算下从零训练了 200 多个多模态大语言模型，以拆解标准视觉编码器中捆绑的三个选择：单独预训练、视觉专用参数以及置于 LLM 之前的位置。他们发现编码器预训练是可选的（最多只能与从零训练持平），视觉专用参数是必需的（无编码器模型需要约 3 倍计算才能追上），而位置也是可选的——通过一种“融合内”方法，在 LLM 前 8 层添加零初始化的视觉专用权重。 这项大规模受控研究为多模态 LLM 设计提供了可操作的指导，表明从业者可以跳过昂贵的视觉编码器预训练并避免单独的编码器模块，同时仍然需要专用的视觉参数。它直接回应了当前实验室之间的分歧——有的放弃编码器，有的从零训练，有的重新引入编码器——并指出已发表模型因数据和计算不同而无法解决该问题。 该研究使用 Qwen3-1.7B 和 4B 骨干网络，配备 0.4B 视觉参数，缩放阶梯覆盖 0.6B 到 6.4B，采用 Cambrian 的 16 个 448px VQA 基准和 12 个语言基准。将 MetaCLIP 预训练延长 6.5 倍使 ImageNet 线性探测准确率从 80.4% 提升到 84.4%，但并未改善 VQA；“融合内”方法在 1.7B 到 6.4B 范围内与编码器性能相当，且首 token 时间降低约 13%，在 1.7B 时第 1–8 层的视觉专用分支达到 45.0 VQA，而编码器为 44.4。

reddit · r/MachineLearning · /u/trungh98 · 11月15日 17:38

**背景**: 多模态 LLM 通常将视觉编码器（常在图像-文本数据上预训练）与语言模型结合，标准配方捆绑了三个选择：编码器的单独预训练、仅视觉 token 使用的参数，以及将编码器置于 LLM 之前。目前各实验室对编码器是否必要存在分歧，有的模型完全放弃编码器，有的则从零训练。本文通过在同一数据上从零训练所有模型，并将编码器预训练计入同一计算预算，来分离每个选择的影响。

## [美团开源 LongCat-2.5：1.6 万亿参数智能体模型，训练未用英伟达 GPU](https://the-decoder.com/meituan-releases-a-1-6-trillion-parameter-agent-model-that-never-touched-an-nvidia-gpu/) ⭐️ 8.0/10

美团旗下的 LongCat 团队在模型正式发布一周后，公布了 LongCat-2.5 的权重。该模型拥有 1.6 万亿参数，专为编程等长周期智能体任务设计；官方称其训练全程使用中国华为昇腾加速卡，未使用英伟达 GPU，并以 MIT 许可证发布，可商用。 这是 AI 硬件多元化的重要里程碑，表明前沿规模模型可以不用英伟达 GPU 训练，中国国产加速卡能够支撑大规模训练。其 MIT 许可证及与 Claude Opus 5 接近的基准表现，也使其成为智能体 AI 开发者可信的开源权重选择。 LongCat-2.5 每个 token 激活约 480 亿参数，支持文本、图像和视频输入，在 Terminal Bench v2.1 上得分 88.4，略低于 Claude Opus 5 的 89.1。它拥有 100 万 token 的上下文窗口，面向视觉编程和仓库级任务。

telegram · zaihuapd · 11月15日 11:08

**背景**: 华为昇腾是海思自 2018 年推出的 AI 加速芯片系列，在出口管制背景下日益成为中国替代英伟达 GPU 的选择。Terminal Bench 是衡量 LLM 智能体执行真实终端任务能力的基准，2.1 版本修复了部分任务并引入持续验证。LongCat-2.5 是美团面向长周期智能体任务的原生多模态模型，将视觉信号转换为离散 token。
