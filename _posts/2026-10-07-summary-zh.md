## [OpenAI 声称 AI 解决了 500 个顶级未解数学问题中的 90 个](https://openai.com/index/sharing-ai-progress-in-mathematics/) ⭐️ 9.0/10

OpenAI 发布了针对 500 个顶级未解数学问题中 90 个的 AI 生成证明，其中包括希尔伯特第十问题（在 ℚ 上）、唯一游戏猜想、巴内特猜想以及朗道-西格尔零点不存在性等重大猜想。该公司在 GitHub 上公开了 Lean 证明形式化代码和研究细节，并声称这些结果来自一个内部前沿模型。 这标志着数学发现可能迎来范式转变，表明 AI 能够攻克数十年来人类难以解决的问题，并引发了关于数学理解与数学之美本质的根本性追问。从图论到复杂性理论再到数学物理，所涉领域的广泛性预示着自动定理证明可能很快成为纯数学研究的标准工具。 这些证明以 Lean 形式化并托管在 GitHub 上，其中排名最高的已解决问题包括希尔伯特第十问题（在 ℚ 上，排名第 22）、唯一游戏（排名第 29）、安德森模型扩展态问题（排名第 31）以及时空彭罗斯不等式（排名第 37）。社区成员指出，巴内特猜想等某些证明乍看之下似乎不难理解，但其完整意义和正确性仍在评估之中。

hackernews · OpenAI Blog · 10月6日 22:17 · [社区讨论](https://news.ycombinator.com/item?id=49984923)

## [弗朗西斯·哈尔岑因冰立方中微子观测站获 2026 年诺贝尔物理学奖](https://www.nobelprize.org/prizes/physics/2026/) ⭐️ 9.0/10

瑞典皇家科学院于 2026 年 10 月 6 日宣布，将 2026 年诺贝尔物理学奖授予美国威斯康星大学麦迪逊分校的弗朗西斯·哈尔岑，以表彰他对冰立方中微子观测站的决定性贡献以及发现天体物理起源的高能中微子。哈尔岑早在 1988 年就提出了在南极冰层中探测中微子的构想，并领导该项目直至 2010 年建成。 该奖项标志着中微子天文学这一全新观测窗口获得认可，它与光学天文学和引力波天文学共同构成多信使天文学体系。冰立方探测到的天体物理中微子为研究宇宙中最高能、原本不可见的物理过程打开了大门。 冰立方是一个立方公里级的探测器，由数千个数字光学模块组成，这些模块被布放在南极阿蒙森-斯科特站冰层下 1450 至 2450 米深处的缆绳上。它通过探测中微子与冰作用产生带电粒子时发出的切伦科夫辐射来工作，其升级项目已于 2026 年 2 月成功部署。

hackernews · solarist · 10月6日 09:48 · [社区讨论](https://news.ycombinator.com/item?id=49976265)

**背景**: 中微子是一种几乎无质量、不带电的基本粒子，由恒星内部的核反应、超新星爆发和放射性衰变产生；它们只通过弱核力和引力发生作用，因此极难探测。中微子天文学通过观测这些粒子来研究光学望远镜无法触及的宇宙高能非热过程。冰立方建成于 2010 年，是世界上最大的中微子探测器，也是欧洲核子研究中心（CERN）认可的实验。

## [Mistral 发布 Mistral Large 4：在欧洲训练的 1 万亿参数模型](https://mistral.ai/news/mistral-large-4//) ⭐️ 8.0/10

Mistral AI 发布了 Mistral Large 4（ML4），这是一个最先进的开放权重多模态模型，总参数量达 1.05 万亿，激活参数 520 亿，并配备 1.6B 视觉编码器，完全在 Mistral 位于欧洲的自有数据中心内、基于 3800 块 NVIDIA Grace Blackwell GPU 从零训练而成。CEO Arthur Mensch 于 2026 年 10 月 6 日在阿布扎比 AI Everything 大会上介绍了该模型，并强调其在视觉和网络安全基准上的强劲表现。 这是欧洲实验室发布的一款重要前沿模型，表明约 4000 块 GPU 的集群就能几乎追平 Kimi K3 等中国顶级开源模型，并超越其他领先的 SOTA 系统，这引发了关于前沿训练算力效率的讨论。它同时对欧盟数字主权具有重要意义，因为训练和推理都在欧洲境内完成，也为寻求替代美国和中国模型的企业（尤其是网络安全场景）提供了有力选择。 该模型采用细粒度混合专家（MoE）架构，总参数 1.05 万亿、激活参数 520 亿，外加一个 1.6B 视觉编码器，其推理模式仅提供“none”和“high”两档。早期测试者发现推理档位在实际效果上差别不大，“high”有时甚至比“none”产生更少的输出 token，但视觉输出表现明显出色；有基准测试显示其成本仅为 Mistral Medium 3.5 的十分之一，准确率却从 58% 提升到 74%。

hackernews · Philpax · 10月6日 13:15 · [社区讨论](https://news.ycombinator.com/item?id=49977979)

**背景**: 混合专家（MoE）是一种架构，每个 token 只激活模型参数的一部分（此处为 1.05 万亿中的 520 亿），从而在较低推理成本下实现更大的总容量。NVIDIA 的 Grace Blackwell 是将基于 Arm 的 Grace CPU 与 Blackwell GPU 结合的算力平台，通常以机架级系统形式部署，用于大规模 AI 训练。Mistral AI 是一家法国公司，定位为欧洲领先的前沿 AI 实验室；开放权重模型指训练后的参数可被下载并自行部署的模型。

## [OpenAI 推出 Decisions API 公开测试版](https://developers.openai.com/api/docs/guides/decisions) ⭐️ 8.0/10

OpenAI 已推出 Decisions API 的公开测试版，这是一个新的端点，返回快速的“是/否/置信度”分类结果，而不是自由生成的文本。该 API 通过专用的 /v1/decisions 端点访问，并支持诸如所提及的“gpt-6-luna”等模型。 这标志着 OpenAI 开辟了一个新的产品类别，专注于“系统一”式的快速决策，可能重塑开发者构建分类和路由功能的方式。同时，随着更便宜的专用决策 API 与通用大语言模型竞争，这也加剧了关于 AI 模型是否正在商品化的争论。 该 API 返回带有置信度分数的“是/否”答案，这通常就是应用所需的全部内容，并且可能比生成完整文本更便宜。社区成员已将其与 Jev 和 Mercury Decide 等替代方案进行了测试，但结果尚属初步，且基于不到 600 次调用。

hackernews · chiefstorm · 10月6日 20:57 · [社区讨论](https://news.ycombinator.com/item?id=49984025)

**背景**: 大语言模型传统上生成自由形式的文本，但许多应用只需要一个简单的决策，例如“是/否”或置信度分数。像 Jev 和 Mercury Decide 这样的专用决策 API 应运而生，以更低的延迟和成本满足这一需求。OpenAI 进入这一领域表明，快速且经过校准的分类正在成为一个独特且竞争激烈的类别。

## [谷歌发布 EmbeddingGemma 2：Apache 2.0 开源多模态嵌入模型](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) ⭐️ 8.0/10

谷歌 DeepMind 发布了 EmbeddingGemma 2，这是一款 740M 参数的开放权重多模态嵌入模型，采用商业友好的 Apache 2.0 许可证，基于 Gemma 4 架构构建。它可将文本、图像、视频帧和音频映射到统一的向量空间，配套的 Google AI Edge Gallery 和 Mac 版 Foresight 已新增演示，未来数周还将通过 ML Kit 向 Android 开放。 对嵌入模型而言，Apache 2.0 开源许可尤为重要，因为应用通常需要计算并存储成千上万甚至数百万个向量，若模型是专有且仅限托管，一旦厂商停用该模型，现有索引就可能失效。同时，随着 LLM 和智能体工作流越来越需要高效的本地检索，这款轻量级、多模态、适合端侧部署的模型正好填补了市场空白，并避免了按请求计费的 API 成本。 EmbeddingGemma 2 是 10 亿参数以下最强的多模态嵌入模型之一，纯文本模式为 270M 参数，文本加视觉模式为 440M 参数，并支持 Matryoshka 表示学习（MRL），可将原生 768 维向量截断为 128、256 或 512 维后重新归一化。社区成员还提出了关于二进制量化方法是否与该模型兼容的开放技术问题。

hackernews · ilreb · 10月6日 16:03 · [社区讨论](https://news.ycombinator.com/item?id=49980487)

**背景**: 嵌入模型将文本、图像等非结构化数据转换为数值向量，使相似内容在共享向量空间中彼此靠近，从而支撑语义搜索、推荐和检索增强生成等应用。多模态嵌入模型进一步将这一能力扩展到多种数据类型，而 Matryoshka 表示学习则让同一个模型可以输出可截断且质量损失很小的向量。Apache 2.0 是一种宽松的自由软件许可证，允许出于任何目的使用、修改和再分发且无需支付版税，因此被广泛用于商业 AI 部署。

## [OpenTPU：由 AI 自身设计的开源 AI 加速器](https://github.com/FeSens/openTPU) ⭐️ 8.0/10

OpenTPU 是一个由 AI 智能体自行设计的开源 AI 加速器，据称通过递归自我改进循环，从小模型上每秒仅几个 token 提升到 80+ tokens/秒。该项目托管在 GitHub 的 FeSens 仓库下，包含 RTL、指令集架构（ISA）、模拟器、编译器和性能分析器，并支持在 FPGA 硬件上运行 LFM2.5-230M 等现代大语言模型。 该项目表明 AI 智能体能够切实参与硬件设计，有望加速芯片开发周期并降低定制 AI 芯片的门槛。它还引发了关于递归自我改进的更广泛讨论，即 AI 系统迭代优化自身底层硬件和软件栈的能力。 该加速器基于 FPGA 并可重构，项目提供了包括 RTL、ISA、模拟器、编译器和性能分析器在内的完整工具链。所报告的 80+ tokens/秒性能适用于较小的模型，且该项目建立在先前使用相同 AI 驱动技术开发 RISC-V CPU 核心的工作之上。

hackernews · fsbonetto · 10月6日 16:23 · [社区讨论](https://news.ycombinator.com/item?id=49980715)

**背景**: TPU（张量处理单元）是一种专为加速机器学习工作负载而设计的芯片，而 FPGA（现场可编程门阵列）是一种制造后可重新编程的可重构芯片。递归自我改进是指 AI 系统重写并测试自身代码以自我提升，这一概念常在 AGI 讨论中出现。OpenTPU 将这些理念结合，利用 AI 智能体设计出可运行语言模型的基于 FPGA 的推理加速器。

## [合成先验 Transformer 实现真实语言的上下文学习](https://www.reddit.com/r/MachineLearning/comments/1wyzhdw/learning_to_learn_a_language_incontext_learning/) ⭐️ 8.0/10

一个 3 亿参数的字节级 Transformer，仅使用由随机采样的循环因果模型生成的合成序列进行训练，在权重冻结的情况下即可在上下文中预测真实自然语言。在六种语言（英语、中文、印地语、阿拉伯语、日语、韩语）上，其下一字节预测在阅读一百万字节的维基百科文本后，从每字节 8 比特降至每字节 0.9–2.4 比特。 这表明上下文语言学习能力可以源自纯粹合成的、非语言先验，将先验拟合网络（TabPFN 背后的思想）从表格数据扩展到结构化序列。它为元学习和语言建模提供了一条新路径，使模型在测试时无需梯度更新即可适应新语言。 同一模型还能在上下文中学习计数、比较数字、近似加法，以及预测素数或 Kolakoski 序列等确定性序列。不过，由于测试时最多只看到一百万字节的某种语言，它在文本上的表现仍远逊于在数万亿 token 上训练的经典语言模型。

reddit · r/MachineLearning · /u/cbl007 · 10月6日 10:50

**背景**: 先验拟合网络（PFN）是在显式先验生成的合成数据集上预训练的神经模型，能够完全在上下文中对新数据集进行贝叶斯预测，而无需重新训练；TabPFN 是表格数据领域的著名例子。字节级 Transformer 直接处理原始字节而非分词后的子词，避免了分词选择问题。这项工作通过定义语言先验将 PFN 思想扩展到自然语言：每条训练序列都来自随机采样的循环因果模型，相当于每个样本都创造一种新的合成“语言”。
