## [Moderna 与默克的 mRNA 癌症疫苗将黑色素瘤死亡和复发率降低 42%](https://arstechnica.com/health/2026/10/personalized-mrna-cancer-vaccine-cut-melanoma-death-recurrence-by-42/) ⭐️ 9.0/10

Moderna 与默克报告称，其个性化 mRNA 癌症疫苗 mRNA-4157（V940）联合 Keytruda 在 3 期试验中使高危黑色素瘤患者的死亡或复发风险降低了 42%。详细结果在部分数据于社交媒体泄露后公布，两家公司计划在医学会议上展示完整数据。 这是个性化 mRNA 癌症疫苗的一项重大临床里程碑，证明 mRNA 平台不仅在传染病领域有效，还可能开启肿瘤学的新时代。它可能重塑黑色素瘤及其他癌症的治疗范式，并对 Moderna 的商业模式和整个生物技术行业产生深远影响。 该试验 KEYNOTE-942 是一项 2b 期研究，纳入了 157 名高危 III/IV 期黑色素瘤患者；疫苗根据每位患者的肿瘤突变定制。单独使用 Keytruda 的复发或死亡绝对风险为 30%，联合治疗降至 18%，但由于预期过高，股价在积极数据公布后仍下跌。

hackernews · _Microft · 10月25日 19:29 · [社区讨论](https://news.ycombinator.com/item?id=50235217)

**背景**: 个性化 mRNA 癌症疫苗通过测序患者肿瘤以识别新抗原，然后将这些靶点编码在 mRNA 中，训练免疫系统攻击癌细胞。mRNA-4157 与帕博利珠单抗（Keytruda）联合使用，后者是一种帮助 T 细胞对抗癌症的免疫检查点抑制剂。这种方法通过为每个个体的癌症量身定制治疗，代表了传统疫苗的转变。

## [俄勒冈警方就一名警员的记录报价 250 万美元](https://theintercept.com/2026/10/01/oregon-police-misconduct-public-records-cost-fee/) ⭐️ 8.0/10

据报道，尤金警察局告知一家当地新闻媒体，处理一项关于一名警员的公共记录请求将需要至少 44,816 小时的员工时间，费用约为 2,484,599.04 美元。这一估算相当于约 21 年的工作量，由 The Intercept 报道后引发了关于透明度和《信息自由法》滥用的广泛讨论。 过高的费用估算实际上可能阻止记者和公民获取公共记录，从而削弱政府问责制和透明度。此案凸显了人们日益担忧的问题：机构可能利用高昂费用作为手段，阻挠对警察不当行为的审查。 为一名警员的记录报价约 250 万美元，是基于估计的 44,816 个员工小时，一位评论者指出这相当于约 21 年的全职工作。俄勒冈州的公共记录法通常允许机构收取员工时间和复制费用，但如此极端的估算引发了质疑：这些费用是否被用来拒绝访问，而非收回成本。

hackernews · tdeck · 10月25日 18:04 · [社区讨论](https://news.ycombinator.com/item?id=50234232)

**背景**: 公共记录法，如俄勒冈州的 ORS 192.410 至 192.505 以及联邦《信息自由法》（FOIA），旨在让公众获取政府文件，同时平衡政府的高效运作。机构通常可以收取合理的搜索、审查和复制记录的费用，但许多法律包含条款，当披露符合公共利益时（尤其是对记者）可减免费用。当机构施加过高的费用时，请求者可能面临实际上的访问拒绝，这种做法有时被称为“FOIA 滥用”或“基于费用的拒绝”。

## [Brotli 高危漏洞扩展至 Python 等 HTTP 组件](https://www.aikido.dev/blog/python-packages-vulnerable-node2shell-brotli-cve-2026-111497) ⭐️ 8.0/10

谷歌 Brotli 解码器 1.0.3 至 1.2.0 版本中存在一个严重缓冲区溢出漏洞（CVE-2026-111497，CVSS 评分 9.2），远程未认证攻击者可发送特制压缩流，导致内存损坏、敏感数据泄露、进程崩溃或可能执行任意代码。该漏洞最初以 Node2Shell 名称披露，后被称为 HTTP2Shell，影响 Node.js 和 Python 的 HTTP 组件，修复版本为 Brotli 1.2.1、brotlicffi 1.2.1.0 以及 Node.js 22.23.4、24.22.1 或 26.12.1。 Brotli 被广泛用于浏览器、服务器和库中的 HTTP 压缩，因此这一高危漏洞使大量 Web 基础设施面临远程入侵风险。使用 Node.js 或 Python HTTP 技术栈的组织必须紧急升级到修复版本，以防止潜在的远程代码执行。 该漏洞是 Brotli 解码器（c/dec/decode.c）中的缓冲区溢出，会破坏相邻的解码器状态内存；用户应升级至 Brotli 1.0.10、1.1.1 或 1.2.1，其中 Python 的 brotli 包需升级至 1.2.1，brotlicffi 需升级至 1.2.1.0。据报道，OpenAI 于今年 2 月发现了该问题，CVSS 4.0 评分 9.2 反映了未认证远程攻击向量和高影响。

telegram · zaihuapd · 10月25日 02:42

**背景**: Brotli 是谷歌开发的一种无损数据压缩算法，常用于压缩 HTTP 响应以加快网页加载。它结合了 LZ77、霍夫曼编码和上下文建模来实现高压缩比。解码器需要处理来自网络请求的不可信压缩数据，因此其中的内存安全漏洞尤其危险。
