## [OpenAI 发布 GPT-6.1 Sol，价格仅为 Astra 的五分之一](https://openai.com/index/introducing-gpt-6-1-sol/) ⭐️ 8.0/10

OpenAI 发布了 GPT-6.1 Sol，声称其在编程、计算机操作和专业工作方面具备接近 Astra 的智能水平，而标准 API 的输入和输出 token 价格仅为 Astra 的五分之一。该模型已通过 OpenAI API 以 gpt-6.1-sol 的名称提供，定价为每百万输入 token 2 美元、每百万缓存输入 token 0.10 美元、每百万输出 token 10 美元，但尚未在 ChatGPT 中上线。 此次发布加剧了前沿 AI 实验室之间的价格战，缓存输入价格比标准输入低 95%，比 GPT-6 Sol 的缓存价格便宜 50%，这可能大幅降低 Codex 等对成本敏感的工作流的开销。同时，GPT-6.1 Sol 在 GPT-6 Sol 发布仅七天后就将其取代，也引发了外界对 OpenAI 模型命名和定位策略的质疑。 GPT-6.1 Sol 在 GPT-6 系列中定位低于旗舰型号 GPT-6 Astra；OpenAI 会自动缓存 1024 个 token 及以上的提示，并对每个缓存提示收取缓存写入费用，无论该缓存前缀之后是否被再次读取。据 Artificial Analysis 称，GPT-6.1 Sol（xhigh 档）的得分比 GPT-6 Astra 高 1 分，而每任务成本不到后者的 15%；Devin 报告称其在低 effort 档下以每任务 0.21 美元的成本获得 58.1% 的得分，是其排行榜上所有每任务成本低于 0.30 美元的模型中得分最高的。

hackernews · OpenAI Blog · 9月29日 17:06 · [社区讨论](https://news.ycombinator.com/item?id=49896586)

**背景**: OpenAI 的 GPT-6 系列包括旗舰模型 Astra 和较低端的 Sol 模型；Astra 在 FrontierMath、ARC-AGI-3 等基准测试中名列前茅，并拥有 100 万 token 的上下文窗口。GPT-6.1 Sol 是 GPT-6 Sol 的增量升级版，在原版 Sol 发布仅数天后推出，OpenAI 将其宣传为同性能水平下最具成本效益的模型。“接近 Astra 的智能”一词指的是性能接近旗舰 Astra 模型，但成本远低于后者。

## [德里将电力损耗从 50%降至 5%](https://spectrum.ieee.org/delhi-electricity-loss) ⭐️ 8.0/10

根据 IEEE Spectrum 的一篇深度报道，德里已将其综合技术与商业（AT&C）电力损耗从约 50%降至约 5%。这一转变发生在 2002 年德里电力局（Delhi Vidyut Board）被拆分为六家继承公司（包括塔塔电力德里配电有限公司）之后。 这是一个罕见的基础设施成功案例，表明猖獗的电力盗窃和长期限电可以在一代人的时间内得到扭转，为其他发展中国家的电力公司提供了可复制的模式。它影响着南亚、非洲和拉丁美洲等配电损耗仍然高企地区的数亿消费者。 这一降损成果既包括技术手段——如高压配电系统、架空集束电缆和先进计量技术——也包括针对企业、居民和腐败公用事业员工窃电行为的商业措施。一个值得注意的副作用是：为防止非法接线而对电力线进行绝缘处理，同时也让猴子能够安全地将这些电线当作在社区之间移动的“道路”。

hackernews · rbanffy · 9月29日 12:43 · [社区讨论](https://news.ycombinator.com/item?id=49892245)

**背景**: AT&C 损耗包括技术损耗（变压器和电线中耗散的能量）和商业损耗（窃电、电表故障、欠费）。私有化之前，国有的德里电力局饱受窃电和投资不足之苦，每天停电数次，电压浪涌损坏电器。私有化将电力公司拆分为独立的发电、输电和配电实体，塔塔电力等私营公司接管了配电区域。

## [网络与移动对话式 AI 代理的隐私分析](https://jorgegarciaherrero.com/wp-content/interactivos/20260916-Prompt-like-a-butterfly-sting-like-a-tracker-(clean).pdf) ⭐️ 8.0/10

一篇题为《像蝴蝶一样提示，像追踪器一样蜇人》的新学术论文对网络和移动对话式 AI 代理如何处理用户数据进行了隐私分析，考察了追踪机制和数据传输实践。该论文在 Hacker News 上引发了 407 个点赞、129 条评论的讨论，聚焦 AI 聊天服务中的隐私漏洞。 随着对话式 AI 代理深度融入日常工作流程，理解它们如何收集、传输并可能泄露用户数据，对用户和监管机构都至关重要。该论文的发现可能影响 AI 公司设计隐私保护措施的方式，以及用户评估这些服务可信度的标准。 社区成员指出，ChatGPT 的网页界面会在用户点击发送前，定期将未完成的提示发送到`conversation/prepare`端点，这可能暴露用户的写作节奏和逐步成型的想法。还有人指出，Perplexity 等服务将 URL 中的 UUID 等同于隐私保护，但访问过去的搜索 URL 会暴露完整对话内容。

**背景**: 对话式 AI 代理是用户通过网页浏览器或移动应用交互的语音和文本助手，如 ChatGPT、Google Gemini 和 Perplexity。隐私研究人员研究这些系统如何收集数据，通常发现追踪机制和数据保留实践对用户并不透明。此前的研究已考察过基于 AI 的对话代理的安全和隐私风险，但本文专门分析了网络和移动代理的实现方式。

## [Anthropic：GLM-5.3 与 Claude Mythos 跨越二进制漏洞利用门槛](https://simonwillison.net/2026/Sep/29/anthropic-frontier-red-team/) ⭐️ 8.0/10

Anthropic 的 Frontier Red Team 在其内部二进制漏洞利用基准中随机抽取 100 个任务对多个模型进行评估，发现 GLM-5.3 在 4% 的试验中实现了完整的控制流劫持，Claude Mythos Preview 的成功率为 6%。而此前的模型如 Claude Opus 4.6 和 GLM-5.2 在所有试验中均未成功，这表明一个有意义的能力门槛已被跨越。 这一里程碑表明，前沿 AI 模型正开始自主执行端到端的二进制漏洞利用，这可能大幅降低开发高级网络攻击能力的门槛。它向 AI 安全研究者、政策制定者和防御方提出了紧迫问题：随着能力强大的开放权重模型日益普及，攻击性网络工具将如何扩散。 该评估使用了内部二进制漏洞利用基准中随机选取的 100 个任务，报告的成功率绝对值较低（4% 和 6%），说明这一能力尚处于萌芽阶段而非成熟状态。真正值得关注的是与 Claude Opus 4.6 和 GLM-5.2 的对比——后两者得分为零，而不仅仅是原始百分比本身。

rss · Simon Willison · 9月29日 22:20

**背景**: 二进制漏洞利用是指通过破坏内存等方式，使已编译程序以有利于攻击者的方式违反信任边界的做法。控制流劫持是一类特定的漏洞利用，攻击者通过覆盖返回地址或函数指针等方式重定向程序的执行路径。Anthropic 的 Frontier Red Team 是一个研究团队，专门对前沿 AI 系统进行压力测试，以了解其当前能力并预判新兴风险。卡内基梅隆大学开发的 ExploitBench 等基准采用分层阶梯模型，用于衡量漏洞利用任务上的部分进展。

## [Cloudflare 发布面向 AI Agent 的 cf 命令行工具](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) ⭐️ 8.0/10

Cloudflare 发布了 cf CLI 的开放测试版，这是一个让开发者和 AI Agent 通过命令行调用 Cloudflare 全部 API 的工具。与覆盖约 280 种操作的现有 Wrangler CLI 不同，cf 直接由 Cloudflare 的 API Schema 生成，覆盖超过 3,000 项 API 操作。 通过让数千项 Cloudflare 操作可以在单一的 JSON 优先接口中被发现和执行，cf 降低了 AI Agent 自主管理 Workers、Access、WAF 等基础设施的门槛。这反映了整个行业正从仅面向人类操作者转向专门为智能体自动化设计开发者工具的更大趋势。 cf 以 JSON 作为默认输出格式，并支持命令搜索和引导式发现，使 Agent 能够以编程方式查找、执行并处理操作。Cloudflare 举例称，Agent 可以用同一个工具创建和部署 Worker、监控服务、配置 Access 与 WAF，甚至购买域名，不过该工具目前仍处于开放测试阶段。

telegram · zaihuapd · 9月29日 13:46

**背景**: Cloudflare 是一家主要的云基础设施和安全提供商，其服务包括 Workers（无服务器计算平台）、Access（零信任访问控制）和 WAF（Web 应用防火墙）。Wrangler 是 Cloudflare 长期使用的 CLI，用于构建和部署 Workers 项目，但只覆盖公司 API 的一部分。新的 cf CLI 则是由 Cloudflare 公开发布的 API Schema 生成，该 Schema 记录了全部可用操作。
